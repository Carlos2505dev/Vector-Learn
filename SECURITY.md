# Security Policy

## Supported Versions

Only the latest version of Vector-Learn is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Vector-Learn, please send an e-mail to Carlos Neto at [carlosbezerrajr2007@gmail.com]. All security vulnerabilities will be promptly addressed.

Please include the following information in your report:

- Type of issue (e.g., XSS, CSRF, etc.)
- Location of the issue
- Steps to reproduce
- Potential impact

We will acknowledge your report within 48 hours and keep you informed of the progress of the fix.
